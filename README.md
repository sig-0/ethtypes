## Overview

The `ethtypes` library provides a collection of common Ethereum types implemented in Go. These types are essential for
building various tools and modules within the Ethereum ecosystem. The library aims to standardize and simplify the
development process by offering a consistent set of types that can be reused across different projects.

## Usage

To use `ethtypes` in your project, simply pull it in with:

```shell
go get -u github.com/sig-0/ethtypes
```

To view examples on using the library, please refer to
the [relevant Go doc](https://pkg.go.dev/github.com/sig-0/ethtypes).
